\begin{study}{Exercise \theexercise: play all the main changes in \tunekeys}
Play through the whole form on the main (bold) changes:
\begin{enumerate}\setlength{\itemsep}{0pt}
\item arpeggiate each chord (R 3 5 7);
\item guide tones only (3rd and 7th), with the smoothest voice-leading.
\end{enumerate}
\keyboxes

\smallskip
\textit{Variant:} stay in one area of the fretboard (e.g.\ one position,
within 4--5 frets), then repeat in another area.
\end{study}
